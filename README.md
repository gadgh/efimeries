# Πρόγραμμα Εφημεριών

Εφαρμογή HTML/JavaScript για δημιουργία προγράμματος εφημεριών καθηγητών.

## Χαρακτηριστικά

- Ανάγνωση αρχείων `.fet` και `.xml`
- Ανίχνευση καθηγητών, δραστηριοτήτων, ημερών και ωρών
- Υπολογισμός διαθεσιμότητας σε δύο βάρδιες
- Ορισμός θέσεων εφημερίας
- Αυτόματη κατανομή εφημεριών
- Χειροκίνητη τοποθέτηση καρτών με drag-and-drop
- Αποκλεισμός θέσεων ανά καθηγητή
- Αφαίρεση και επαναφορά καθηγητών
- Εξαγωγή σε CSV
- Εκτύπωση του πίνακα
- Αποθήκευση και φόρτωση ρυθμίσεων

## Εκτέλεση

Δεν απαιτούνται εξωτερικές βιβλιοθήκες ή διακομιστής.

1. Κατέβασε το αρχείο `Eφημερίες_V1&2.html`.
2. Άνοιξέ το σε σύγχρονο πρόγραμμα περιήγησης.
3. Πάτησε **Επιλογή FET**.
4. Επίλεξε ένα αρχείο `.fet` ή `.xml`.

Για δημοσίευση μέσω GitHub Pages:

1. Μετονόμασε το HTML αρχείο σε `index.html`.
2. Μετέφερε το αρχείο στο repository.
3. Άνοιξε **Settings → Pages**.
4. Στο **Build and deployment** επίλεξε **Deploy from a branch**.
5. Επίλεξε branch `main` και φάκελο `/ (root)`.

## Βήματα χρήσης

1. Φόρτωσε ένα αρχείο FET.
2. Επίλεξε τον αριθμό θέσεων.
3. Πάτησε **Όρισε τις θέσεις**.
4. Δώσε όνομα σε κάθε θέση.
5. Πάτησε **Εμφάνιση Διαθεσιμότητας**.
6. Τροποποίησε τη διαθεσιμότητα ή τους καθηγητές αν χρειάζεται.
7. Δημιούργησε εφημερίες αυτόματα ή τοποθέτησε χειροκίνητα τις κάρτες.
8. Εξήγαγε το αποτέλεσμα σε CSV ή εκτύπωσέ το.

## Αλγόριθμοι αυτόματης κατανομής

- **Κλασικός αλγόριθμος**
- **MRV** — εξετάζει πρώτα τις κάρτες με τις λιγότερες επιλογές
- **Backtracking** — δοκιμάζει αναδρομικά εναλλακτικούς συνδυασμούς

Διατίθενται ρυθμίσεις για:

- Αυτόματη ή χειροκίνητη κατανομή
- Τυχαία σειρά καρτών
- Προτεραιότητα σε καθηγητές ή κάρτες
- Επαναλήψιμη ή μη θέση ανά καθηγητή
- Μερική χαλάρωση των στόχων εφημεριών
- Μέγιστο αριθμό προσπαθειών

## Αποθήκευση ρυθμίσεων

Μπορούν να αποθηκευτούν:

- Οι αφαιρεμένοι καθηγητές
- Οι αποκλεισμένες θέσεις ανά καθηγητή
- Τα ονόματα των θέσεων σε αρχείο `.txt`

Το αρχείο καταγραφής χρήσης αποθηκεύεται ως JSON και μπορεί να φορτωθεί ξανά στην εφαρμογή.

## Συμβατότητα

Συνιστώνται σύγχρονο πρόγραμμα περιήγησης:

- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Safari

Όλη η επεξεργασία γίνεται τοπικά στον browser. Δεν απαιτείται σύνδεση ή αποστολή δεδομένων σε διακομιστή.
